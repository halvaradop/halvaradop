### Aura Stack
 
A TypeScript-first ecosystem built around **Web standard Request/Response APIs**, so every package works the same way across Node.js, Deno, Bun, and Edge runtimes.
 
| Package | Description |
|---|---|
| [`@aura-stack/auth`](https://github.com/aura-stack-ts/auth) | Authentication & authorization: OAuth/OIDC, JWT, session management, CSRF protection — 900 peak weekly downloads |
| [`@aura-stack/router`](https://github.com/aura-stack-ts/router) | Type-safe, schema-validated router with middleware, lifecycle hooks, and a typed API client — 748 peak weekly downloads |
| [`@aura-stack/ui`](https://github.com/aura-stack-ts/ui) | shadcn/ui-inspired authentication component registry for React & Next.js |
